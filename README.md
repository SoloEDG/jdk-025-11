# 遗迹探勘

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18225。

校验与构建：`npm run typecheck`、`npm run build`

## 地震勘测（剖面测量）

与确认单格的勘探探针不同，地震勘测沿地图边缘布放震源与接收器，对沿途石层做整条剖面测量。

- **布放约束**：两个端点必须是地图四条边上的非角点，且位于不同的边；路径用 supercover 栅格化得到全部穿越格（擦边、穿角均计入）。
- **读数只给总量**：每条测线只公布两个数——沿线危险格总量与介质衰减总量，绝不泄露任何单格答案；未被任何测线覆盖的位置始终保持未知。测线可重叠交叉，靠多线联合缩小地下结构的可能范围。
- **联合求解、保留欠定**：已揭数字、全局危险总数、探针/旗标结论与全部测线读数进入同一个约束求解器（CSP），枚举所有可行地下结构。存在多解时只输出所有解的共同结论（并在截断时显式标注欠定），每条推断都标注依赖哪些测线，不会把某个同样符合读数的解误画成唯一结构。
- **下一条推荐**：仅基于公开信息对可行解做期望信息增益（读数香农熵）估计，再结合剩余电量、布置距离（耗电）与重叠度排序；推荐过程不读取任何暗格真值。
- **一致性保证**：耗电量按路径长度计算；布放草稿未发射不耗电、不入档，刷新即消失；重测同一剖面被拒绝且不重复扣电；已公布读数、耗电与探险结算在重测、撤回与刷新后不重复、不丢失，存档加载时会重算每条测线的路径与读数进行校验，旧存档自动迁移。
